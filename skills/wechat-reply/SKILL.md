# 微信回复建议

## 前置
先调用 `get_account_status` 确认微信已登录、密钥就绪（key_ready=true），并核对当前登录账号
是否是用户想操作的那个。若用户想查的账号不是当前登录账号，提示其切换微信登录后重试。

## 流程
1. `get_recent_messages(<用户提到的名字>, limit=50)` → 拿近期上下文（时间正序）。contact 直接填
   名字即可，不必先 `list_contacts`；若返回 `need_confirm`（重名），**列出候选让用户确认**，
   不要猜，确认后用候选的 username 重试。
2. 若近期信息不足或需要背景，`search_messages(<关键词>, contact=<username>)` 找证据片段，
   需要原文再 `get_message_context`；要整段原文命中时用 `search_history`。
   （检索查询本地索引；若提示索引为空，先让用户运行
   `uv run --directory ~/agent-wechat agent-wechat export`）
3. 综合分析后生成 **2-3 条风格不同的候选回复**，每条附一句适用场景说明：
   - 贴合对方的语气与关系远近（看对方怎么写的）
   - 回应对方最后一条消息的实际内容，不要答非所问
   - 注意未回复的消息（对方最后几条是否在等我回应）
4. 呈现保持聊天的自然语气，不要写成正式邮件。

## 禁止
- 不要在未经用户确认时把聊天内容写入任何文件
- 不要把聊天内容发到任何外部服务（仅本地处理）
- 不要读取除用户指定联系人以外的会话内容
